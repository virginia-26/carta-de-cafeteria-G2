# Wöllen - Carta de la cafetería

Sitio web de la carta digital de Wöllen, heladería y cafetería (Swiss Ice Cream & Specialty Coffee).
Trabajo del Taller de Desarrollo Web, UCC.

## Integrantes
- Valentina Sanchez
- Virginia Enrico
- Maria Emilia Lasa 

## Qué tiene el sitio
- Inicio con novedades, presentación del local y video.
- Carta con categorías: Desayunos y Meriendas, Tortas y Tostados, Dulces, Cafetería, Bebidas y Copas Heladas.
- Login y registro, para poder dejar una opinión.
- Opiniones de los clientes.

## Tecnologías
- HTML, CSS y JavaScript
- React con Vite
- ESLint, para mantener el código consistente

## Cómo correrlo
1. Instalar Node.js (versión LTS).
2. En la carpeta del proyecto: npm install
3. Para arrancarlo: npm run dev
4. Abrir el link que aparece en la terminal (por ejemplo http://localhost:5173).

## Notas
- Las opiniones y el usuario se guardan en el navegador (localStorage), no en un servidor.
